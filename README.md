# Blue

This repo was designed for use with Fedora and tested only with Fedora.

## Requirements

- Bash
- nmap
- Wireshark
- tshark
- Python
- Ansible
- sudo/root access (required for privileged scans)

## Download Instructions

1. Download the download script.

`curl -o ~/Downloads/download.sh https://raw.githubusercontent.com/volshebork/blue/refs/heads/main/download.sh`

1. Make script executable.

`chmod u+x ~/Downloads/download.sh`

1. Run the Download Script.

`~/Downloads/download.sh <destination>`
